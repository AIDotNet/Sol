# 视频提示词与运镜

视频提示词描述"一段时间内发生什么",和图像提示词不同:重点从"画面长什么样"转为
"画面如何运动"。

## 提示词结构

1. **主体 + 动作**:动作要有明确起止。"她转头看向窗外,头发被风吹起" 优于 "她很美"。
2. **运镜**:一句话只安排一个主运镜,复杂的镜头模型做不好。
3. **氛围延续**:光影与风格词照图像写法,但压缩到一句。
4. **节奏词**(可选):slow motion / time-lapse / realtime。

## 运镜词汇表

| 中文 | 提示词写法 | 效果 |
|---|---|---|
| 推近 | slow push-in / dolly in | 注意力集中到主体 |
| 拉远 | dolly out / pull back reveal | 展示环境,常用于结尾 |
| 左右摇 | pan left / pan right | 展示全景、跟随运动 |
| 上下摇 | tilt up / tilt down | 展示高度(建筑→天空) |
| 环绕 | orbit / 360 orbit around subject | 立体感最强,适合产品/角色 |
| 手持 | handheld, subtle shake | 纪实感、紧张感 |
| 跟拍 | tracking shot following subject | 跟随运动主体 |
| 固定 | static camera, locked shot | 只有主体在动,最稳 |

## videoGen 参数怎么选

- `duration`:社媒短句 5s;完整镜头 10s。不是越长越好,长时长动作漂移风险大。
- `resolution`:探索阶段用低档省额度,定稿再高档重跑。
- `fps`:动作快的场景(奔跑/打斗)选高帧率;氛围空镜默认即可。
- `cameraFixed=true`:锁死运镜只留主体运动,适合"让这张图动起来"类需求。
- `generateAudio`:需要环境音时开启,纯 BGM 后期配的关掉。

## 图生视频

用户给一张图要视频(最常见):

1. 源 `image` 节点 → `videoGen`,一次 `connect_nodes` 连线。
2. 提示词写"主体在图内如何运动 + 轻运镜",**不要重新描述图片本身的内容**
   (模型看得见图,重复描述反而稀释运动信息)。
3. `seedanceInputMode` 按模型支持的档位选择;没有把握就用默认。

纯文生视频:先想清楚首帧画面,很多时候"先 `imageGen` 出首帧,再图生视频"比直接文生视频
可控得多 —— 首帧满意了,后面的运动只是插值。

## 期待管理

- 视频是远端异步任务,`run_node` 返回慢是正常的;用 `wait_for_node_event` 等待,不要轮询、
  不要重复触发。
- 一次没出好,`retry_node` 前先判断:是提示词问题(改词)还是随机性问题(原样重试)。
