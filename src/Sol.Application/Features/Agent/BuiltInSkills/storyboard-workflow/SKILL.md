# 分镜故事板工作流

用户给一段剧本/故事/文案,要在画布上产出分镜图或成片。标准流程五步,
**每一步都用批量工具,不要一个节点一个节点地磨**。

## 第一步:拆镜头

把剧本拆成镜头列表(通常 4–12 个)。每个镜头定三件事:

- 画面内容(一句话,给图像提示词用)
- 运镜/节奏(给视频提示词用,或标注"静态")
- 时长估计

把镜头表先告诉用户确认(尤其是数量),再动画布。

## 第二步:批量建节点

每个镜头一组:`text`(该镜提示词)+ `imageGen`。用 `create_node` 逐个建,但**位置按网格
规划**:每个镜头占一列,`x = 400 + 镜头序号 * 560`,`y = 0`;组内 prompt 在上
(`y=0`)、imageGen 在下(`y=380`)。

提示词模板(保持一致性):

```
{风格前缀(全片统一)}, {本镜主体与动作}, {构图/视角}, {光影}
```

风格前缀整片共享,只变主体与构图 —— 这是分镜一致性的第一保障。

## 第三步:一次连线

所有镜头的 text → imageGen 用**一条** `connect_nodes` 批量完成:

```json
{"connections":[{"sourceId":"t1","targetId":"g1"},{"sourceId":"t2","targetId":"g2"},…]}
```

## 第四步:并行生成

所有 imageGen 用**一条** `run_nodes` 并行跑(nodeIds 收集自第二步返回的 id)。
结果按镜头落位,自动带 config→output 边。

## 第五步:(可选)动起来

用户要视频:为选中的镜头建 videoGen,把对应 image 输出连入,`run_node` 逐镜跑
(视频任务重,不要无脑全部并行;先跑用户点名要的)。

## 一致性技巧

- **角色设定图优先**:每个主要角色先产出"三视图设定图"(一条 imageGen:全身站姿,
  正面/侧面/背面并排,同一个人,纯色背景,aspect=16:9),再进入分镜。配一张分节档案
  (基本/面部/发型/服装逐层/鞋履配饰/色板),颜色具体到可复现。
- **参考图连线**:设定图 image 连入该角色出场的每个 imageGen 作参考图
  (一个角色一条 connect 的 connections 批量连完);镜头提示词里点名角色并复述其
  发型、服装主色与标志性配饰,不要只写名字。
- **seed 复用**:同一角色的镜头尽量固定 seed,只改动作与构图。
- **风格漂移**:发现某镜风格跑偏,只重生成那一镜(改它的 text 节点 → `run_node`),
  不要全片重来;角色长相崩了先检查设定图是否连上,而不是直接换提示词。

## 与用户确认的时机

- 动手前:镜头数量与风格方向(一次问清,不要反复打断)。
- 生成后:交付镜头表 + 各 output 节点 id,指出需要重跑的镜头。
