# 批量变体与风格探索

用户说"多来几个方案"/"换风格试试"/"这个再优化下",本质是**控制变量实验**。
核心原则:一次只变一个维度,并行探索,快速淘汰。

## 两种矩阵

### 风格矩阵(变风格,锁内容)

同一主体与构图,3–4 种风格。每个风格一个 `imageGen` 节点,提示词只有风格段不同:

- 节点布局:同一行,`y` 相同,`x` 等距。
- 一条 `connect_nodes` 连好所有 text → imageGen。
- 一条 `run_nodes` 全部并行跑。

适合:定风格方向、给用户选择题。

### seed 矩阵(变随机性,锁提示词)

提示词完全相同,`seed` 不同(或 count=4)。适合:"这张图不错,但再抽几次卡"。

- 首选:同一节点 `count=4` 直接抽 4 张;不满意再固定 seed 微调提示词。
- 只有当用户要"并排对比不同 seed"时才建多个节点。

## 淘汰流程

1. 生成后用 `get_node_status` 确认全部成功(并行批次里可能有个别失败)。
2. 让用户点选保留的输出(用户会选中节点),或按用户描述的特征定位节点
   (画布上下文里选中的就是用户挑好的)。
3. 淘汰的节点:**不要主动删**,除非用户明说;建议用户自己清理或确认后用 `delete_nodes`。

## 变体方向速查

| 用户说 | 变的维度 | 保持不变 |
|---|---|---|
| "再来几张类似的" | seed / count | 提示词全文 |
| "换个风格" | 风格段 | 主体、构图、光影 |
| "更亮一点/更暗一点" | 光影词 | 其他全部 |
| "近一点/远一点" | 构图/视角词 | 其他全部 |
| "横的变竖的" | aspect | 提示词(seed 也尽量保留) |
| "这个动作再来一次" | 无(原样重试) | 一切,直接 retry/run |

## 经济性

- 探索阶段 `quality` 用低档,方向定了再高档精出 —— 提醒用户这一点,省额度。
- videoGen 不要用于风格探索:先用 imageGen 定画面,再图生视频。
- 每批探索结束后在最终答复里说明:哪些节点是候选、哪些是定稿,方便用户回溯。
